# X Article 粘贴格式规则

X Article 编辑器对 markdown 支持弱且不稳定。`md2x.py` 按以下规则转纯文本，
转完人工通读一遍是硬性步骤。

| Markdown | 转后 |
|----------|------|
| `#` / `##` 标题 | 纯文本行，前后各一空行 |
| `**加粗**` / `*斜体*` | 去标记留文字（语气靠文字本身） |
| `[文字](url)` | `文字（url）` |
| `![](alt)` | `[图N]`，文末附"配图清单" |
| `-` / `1.` 列表 | 保留原符号 |
| `>` 引用 | 去 `>` 留文字 |
| 表格 | 转"项：值"列表；复杂表拆成段落 |
| `---` 分割线 | 空行 |
| 代码块 | 去围栏，内容缩进 4 格 |
| frontmatter | 整块丢弃 |

## 写作时就按 X 想

- 段落短：手机阅读每段 ≤4 行
- 小标题就是一句话，不依赖加粗撑结构
- 数字、专有名词第一次出现就写全（剥离标记后无高亮可依靠）
- 需要强调的词：换说法前置，不要靠 `**`

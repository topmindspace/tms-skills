## 原创与虚构声明（重要）

本目录 16 张示例图均为**原创设计**，仅用于演示 8 种风格的**设计语言**
（构图公式、配色、文字层级、安全区），不临摹任何第三方封面。
图中所有标题文案、数字、品牌名、署名均为**虚构演示内容**，
如"星尘 OS 3.0"（虚构品牌）、"7天玩转提示词""30天AI绘画挑战"（虚构标题）、
"@阿狐画画"（虚构署名）——直接复用前请换成自己的真实标题；
凡封面上的数字必须在正文中有出处，严禁编造数据。

## 安全区说明（重要）

所有示例的标题字与关键元素都落在**中央垂直 60% 安全区**（画面垂直 20%~80%）内——
这正是 `900×383` 中央裁剪版（1200×675 上下各裁约 12.2%，保留垂直 12.2%~87.8%）
标题不被裁掉的原因。安全区取 60% 是留了设计裕度，比实际裁剪线更保守。
自己组 prompt 时务必遵守：标题/关键主体不得超出上下各 20% 的禁区，否则公众号版会被切掉。
反例：胶囊标签条/副标题横条/署名行压在底部 80% 以下时，`-wechat.png` 里会只剩半截或完全消失。

## 复用声明

**示例图可直接拿去用/改，作封面底图或风格参考。**
拿去用时建议按 `scripts/crop-cover.py` 的流程重新裁剪双尺寸并按包规约命名落盘；
改图时保留原风格的配色与版式语言，只换主体与标题字，以维持系列感。
注意：示例标题均为虚构演示文案，直接复用前请换成自己的真实标题。

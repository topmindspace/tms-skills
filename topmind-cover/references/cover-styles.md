# 封面风格模板

选风格先看题材，再看系列延续性。同一系列固定一个模板，只换主体与标题字。

## 科技深空（默认 · AI/技术题材）

- 深色底（藏青/墨黑）+ 霓虹线条 + 细颗粒星空
- 主体：产品/人物半身，面光干净
- 标题：白色粗黑，字号压住上 1/3
- 例：Manus 2.0、Cue、AI 智能体题材

## 清新浅色（人物/生活/轻题材）

- 米白/浅灰底 + 柔光 + 大面积留白
- 主体居中，神态自然
- 标题：深灰细黑，落在下方 1/4
- 例：卡牌系列人物、随笔

## 国潮撞色（文化/历史题材）

- 朱红/黛青撞色 + 传统纹样暗纹
- 主体：国风人物或器物
- 标题：书法感粗体，竖排亦可

## 硬核评测（产品评测题材）

- 深灰底 + 产品特写 + 数据流装饰
- 标题：黄/白撞色，配 1 个核心数字（如"32%"）
- 忌：数字必须与正文一致，承重数字先核实

## 通用 prompt 组装公式

```
{风格模板一句话}，主体：{主体描述}，
画面中央大标题“{≤10字标题}”，{暗底亮字/亮底深字}，
横构图16:9，主体占画面40%以上，四周留白8%，
极简，不堆砌元素，电影感光影
```

标题字逐字写进 prompt；生成后第一件事就是检查标题字。

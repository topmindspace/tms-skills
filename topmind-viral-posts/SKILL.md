# topmind-viral-posts · X 引流段子/爆款短篇

基于 X 中文区真实高互动帖提炼。目标：**短、真、钩子**——读者 3 秒能看完，忍不住点赞/评论/关注。

## 六大类型

| 类型 | 核心钩子 | 配图建议 |
|---|---|---|
| 1. 干货忠告型 | "新手最容易犯的错误" | 标语图 / 风景（远眺感） |
| 2. 互关求粉型 | 直接求 + 承诺回关 | 宠物（亲和力） / 美女（吸睛） |
| 3. 自嘲幽默型 | 具体数字 + 反差 | 宠物（搞笑） / 奇幻（反差萌） |
| 4. 互动提问型 | 二选一 / 灵魂拷问 | 标语图（二选一文字） / 风景 |
| 5. 打卡日常型 | 日拱一卒 + 祝福 | 风景（日出/坚持感） / 宠物（陪伴） |
| 6. 新人报到型 | 拟人化 + 求带 | 宠物（拟人化） / 美女（新人设） |

详见 `references/patterns.md`（每种类型的真实案例拆解 + 写作公式 + 配图公式）。

## 何时不用

- X 长文（数千字深度稿）→ `topmind-x-article`
- 公众号长文 → `topmind-wechat-post`
- 干货短文（第三方客观口吻）→ `topmind-briefs`
- 需要深度论证的严肃话题（本技能只做短平快引流）

## 写作铁律

1. **短句分行**：一行一个意思，不超过 15 字；段与段空一行。
2. **口语化**：说人话，不说书面语。"蓝朋友""上岸""串门"比"用户""成功""交流"好。
3. **具体数字**：4869 个粉 > "几千个粉"；3 小时 > "刚才"。
4. **互动钩子**：每帖至少一个——提问、二选一、求互关、求评论。
5. **Hashtag**：互关类必带 `#蓝V互关 #follow`；干货类可带 `#涨粉`；日常类可带 `#日拱一卒`。
6. **表情点缀**：1-3 个，不要堆。😭😎🤝 比纯文字有温度。
7. **去 AI 味**：不用"首先其次最后"，不用"综上所述"，不用感叹号堆砌。

## 配图铁律（每帖 1 张，必配）

段子不带图 = 白发。配图走 `topmind-cover` 技能出图，5 大图库按类型匹配：

| 图库 | 适用类型 | 出图要点 |
|---|---|---|
| **美女** | 互关求粉 / 新人报到 | 吸睛但不低俗，自然笑容，生活感；避免过度修图网红脸 |
| **宠物** | 互关 / 自嘲 / 打卡 / 新人 | 猫为主（用户偏好），狗/鸟点缀；表情生动、有故事感 |
| **风景** | 干货 / 提问 / 打卡 | 日出/远眺/星空，配"坚持""远方"意境；16:9 横版 |
| **奇幻** | 自嘲 / 提问 | 异星风光、奇特地貌、超现实；反差萌，引发好奇 |
| **标语** | 干货 / 提问（二选一） | 大字报风格，一句话金句 + 纯色/渐变底；字少而大 |

**配图流程**：
1. 写完段子 → 按上表选图库
2. 调 `topmind-cover`：选风格 → 按配方组 prompt → 出图
3. 尺寸：X 单图 1200×675（16:9）；多图也可用 1:1
4. 检查：图与文案情绪一致，不抢戏，不低俗

## 工作流

1. **选类型**：看用户要什么效果（涨粉→互关型/新人型；互动→提问型/自嘲型；立人设→干货型/打卡型）。
2. **套公式**：从 `references/patterns.md` 取对应公式，填内容。
3. **配图**：按"配图铁律"选图库，走 topmind-cover 出图。
4. **自检**：读一遍，删掉任何"正确的废话"；确认有钩子、有 hashtag、有配图。
5. **交付**：正文 + 配图（或配图 prompt），一次 3-5 条，用户挑。

## Output Contract

- 输出：3-5 条独立短帖，每条 50-150 字。
- 每条配：1 张图（已生成）或 1 个可直接用的出图 prompt（含图库类型 + 风格 + 画面描述）。
- 格式：纯文本，短句分行，hashtag 放末尾；配图说明另起一行。
- 不编造用户数据：粉丝数、收益等数字用户给才写，不给就用模糊表述。

## Operating Rules

1. **不碰政治、色情、medical advice**。
2. 中文区风格，不硬翻英文 meme。
3. 互关帖不承诺做不到的事（如"必回关"写成"尽量回关"除非用户明确）。
4. 美女图不低俗：自然、生活感、有笑容；用户明确要"流量向"时再放开。
5. 宠物图猫优先（用户偏好），外星/奇幻图取异星风光和奇特地貌。

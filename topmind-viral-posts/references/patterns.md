# 六大型写作公式 + 真实案例拆解

> 案例均来自 2026-10-03 X 中文区真实帖（截图），数据为当时互动量。

## 1. 干货忠告型

**公式**：痛点标题 + 3-4 行短句讲透 + 一句话金句收尾

**案例**（David小牛，549 浏览）：
```
新手最容易犯的错误：
以为发完推文就万事大吉。
不给别人点赞评论，
你的主页就是个无人孤岛。
先学会给别人鼓掌，才有人来围观你。
```
**拆解**：标题即钩子；每行 <15 字；"无人孤岛"具象比喻；末句金句反转。

**案例2**（AoXiang.Luffy）：
```
涨粉秘诀
不是有了蓝V就有蓝朋友
而是需要主动去点赞评论关注
不是在大V下面点赞评论回复一条
而是需要主动给每条回复去互
```
**拆解**："不是…而是…"对比结构 ×2，节奏感强。

## 2. 互关求粉型

**公式**：现状/请求 + 回关承诺 + #蓝V互关 #follow

**案例**（仁，37 浏览）：
```
还没来得及回关的朋友请别着急！有时候被限制了，能关注了就会马上回关！ #蓝V互关 #follow
```
**案例2**（Garybird，1113 浏览，44 评论）：
```
本小鸟刚刚开通蓝V了。🐦✓
在地球上还没认识几个人。
有没有愿意和一只灰鸟交朋友的？
我会飞过去关注你。🐦🤝
```
**拆解**：拟人化（"本小鸟""飞过去"）+ 具体承诺（"我会关注你"），评论区炸了。

## 3. 自嘲幽默型

**公式**：具体数字 + 反差自嘲 + 表情收尾

**案例**（土豆哥，182 浏览）：
```
我现在有4869个粉
按理说会发个推特
说大家帮忙冲一波5000
我现在都不发了
因为发了你们也不点关注😭
```
**拆解**：精确数字（4869）建立真实感；"按理说…但我不"反差结构；😭 收尾让人想点关注。

**案例2**（贝拉吖，571 浏览，21 评论）：
```
如何让自己的帖子爆火呢？
难道要在帖子上吼两声？
```
**拆解**：提问 + 荒诞答案，短到 2 行，评论区自然接梗。

## 4. 互动提问型

**公式**：假设场景 + 二选一 + 追问

**案例**（萧火灵，550 浏览，25 评论）：
```
如果有一天
抖音 和 微信 你只能选一个
你会选择谁？？？
```
**拆解**：国民级二选一，人人有答案；三个问号加强语气；评论区天然站队。

## 5. 打卡日常型

**公式**：今日进展 + 心态金句 + 祝福收尾

**案例**（大鹏嚼吧嚼，246 浏览）：
```
每天有增长 日拱一卒
做x 不能等 要多互动 多串门 多交流心得
爆款我不敢想 稳稳的做好自己能写的东西就行了
取长补短 才能走多更久
祝兄弟们早日 上岸
```
**拆解**："日拱一卒"人设标签；"兄弟们""上岸"圈内黑话拉近距离；祝福收尾暖。

## 6. 新人报到型

**公式**：刚来 + 一句话自我介绍 + 求带/求互关

见 Garybird 案例。核心：**低姿态 + 具体行动承诺**（"我会飞过去关注你"比"求互关"强 10 倍）。

## 通用技巧

- **#follow 标签**（孙哥实测）：老外天天搜这个 tag 找人互关，挂上被刷到概率翻倍。
- **发布时间**：中文区早 8-9 点、晚 8-10 点互动最高。
- **评论区运营**：每条评论都回，比发新帖更涨粉（AoXiang.Luffy 公式核心）。

## 配图公式（每类型 1 张）

### 干货忠告型 → 标语图 / 风景
- **标语图**：金句大字（如"先学会给别人鼓掌"）+ 深色渐变底，白字，字占画面 60%
- **风景**：日出/远眺/山顶，配"格局""远方"感；prompt 加 "wide landscape, sunrise, minimalist"

### 互关求粉型 → 宠物 / 美女
- **宠物**：猫咪直视镜头，眼神无辜/期待；prompt："cute cat looking at camera, innocent eyes, soft light"
- **美女**：自然微笑，生活场景；不低俗，不网红脸

### 自嘲幽默型 → 宠物（搞笑） / 奇幻
- **宠物**：猫咪翻车现场/生无可恋表情包感
- **奇幻**：超现实反差（如猫咪宇航员），"我裂开了"的视觉版

### 互动提问型 → 标语图 / 风景
- **标语图**：二选一文字左右分栏，A vs B，大字对比色
- **风景**：岔路口/两条路，隐喻"选择"

### 打卡日常型 → 风景 / 宠物
- **风景**：日出/晨跑/登山，"日拱一卒"的视觉化
- **宠物**：猫咪陪伴工作/看书，温暖日常感

### 新人报到型 → 宠物（拟人化） / 美女
- **宠物**：小猫挥手/探头，"新来的"既视感
- **美女**：新人设，清新自然，"大家好我是新人"
